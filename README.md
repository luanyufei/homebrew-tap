# luanyufei's Homebrew Tap

Official Homebrew repository for macOS tools by [@luanyufei](https://github.com/luanyufei).

## Formulae

| Formula | Description | Install |
|:---|:---|:---|
| [`dwum`](https://github.com/luanyufei/delete_when_unzip_mac) | Delete archives while unzipping with APFS zero-write hole punching | `brew install luanyufei/tap/dwum` |

## How to Install

```bash
# Direct install
brew install luanyufei/tap/dwum

# Or add tap first
brew tap luanyufei/tap
brew install dwum
```
